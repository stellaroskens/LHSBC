LEBANON HIGH SCHOOL BOWLING CLUB — HOMEPAGE ARTWORK PACK
======================================================

This ZIP contains five separate PNG image files with transparent backgrounds,
prepared from the latest approved retro homepage reference.

FILES
01_lhsbc_crest.png
   Club crest / branding.
02_join_the_club_button.png
   Header button. Link it to /our-club until /how-to-join exists.
03_donate_button.png
   Header button. Link to existing /donate.
04_bowling_club_hero.png
   Main Lebanon High School Bowling Club title illustration + tagline.
05_find_out_more_bowling_lane.png
   Large information arrow with bowling lane. Link to /information.

INSTALL IN CURSOR
1. Download and unzip this archive on your Mac.
2. Open your LHSBC project folder in Cursor.
3. Copy the five PNGs to:
      public/assets/canva-assets/final-homepage/
4. Ask Cursor Agent to use these five files on the existing homepage.
5. KEEP the current working homepage and Git backup intact while reviewing.

IMPORTANT
- These are high-resolution, transparent RASTER PNGs with vector-like styling.
  They are not true editable SVG vector paths.
- The graphics were recreated from your reference using image generation,
  so small shape/lettering differences may exist from your Canva original.
- A high-resolution PNG cannot guarantee unlimited vector sharpness.
- Preserve your original high-quality crest file if it more exactly matches
  your approved brand artwork.
- Use actual HTML links/buttons for navigation, rather than relying on
  click targets drawn into the PNGs.
- No Bowl-A-Thon artwork is included.
